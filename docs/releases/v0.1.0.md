# Nmap + Zenmap Web v0.1.0

First stable release of the unofficial browser-accessible container for the
official Nmap 7.991 scanner and matching Zenmap GTK frontend.

## Highlights

- Multi-architecture images for amd64 and arm64.
- Docker Compose and Podman Quadlet examples.
- Non-root desktop with scoped raw-network capabilities.
- Persistent configuration and scan output under `/config`.
- Browser access through noVNC with authenticated VNC by default.
- Automatic Zenmap relaunch without dropping the browser desktop.
- SBOM, provenance metadata, and GitHub artifact attestation.
- Workaround for the upstream Zenmap 7.991 `vl_6_logo` crash.

## Pull

```sh
docker pull ghcr.io/ploos-as/nmap-zenmap:0.1.0
```

See the README for required capabilities and full deployment examples. Do not
expose the unencrypted noVNC service directly to the public Internet.
